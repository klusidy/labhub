Follow these steps to successfully setup *Labhub* on your machine. 

> [!INFO]  
> Windows only! So far *Labhub* was developed and tested on machines with Windows 10+ (64bit). Although *Labhub* itself is a multi-platform solution, many devices only provide windows-specific ways to communicate with them

Make a dedicated folder and download the code from its [repository](https://svn.isibrno.cz/levifot/labhub). Preferably via `git clone` since that enables easier updates in the future but downloading and unpacking a zip file into a dedicated folder will work as well

```bash
git clone https://svn.isibrno.cz/levifot/labhub.git
```

Open powershell, navigate to the project folder and run
```
./install.bat
```
The install script does the following things:
- download embedable python package ([this one]([3.12.1](https://www.python.org/downloads/release/python-31210/))) into a `runtime` folder
- create a virtual environment inside a `.venv` folder
- obtains `pip` (python package manager)
- installs python packages listed in `requirements.txt`
- generates a `run.bat` batch file

And thats it - you're all set! 

To start *Labhub*, just run the newly generated `run.bat` file. You can also copy it to desktop or modify it so that Labhub starts with particular `config` and `profile` files.

```
@echo off

setlocal

REM Absolute install path (generated by install.bat)

set "APP_ROOT=C:\Users\jk\labhub"

REM Always run using project-local venv:

"%APP_ROOT%\.venv\Scripts\python.exe" %APP_ROOT%\launcher\launcher.py" 
--config "%APP_ROOT%\launcher\config_default.yaml" 
--profile "%APP_ROOT%\launcher\profile_default.yaml"
```

To learn more about how these files work, read about [[Configuration]]
